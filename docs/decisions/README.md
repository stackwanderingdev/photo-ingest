# Architecture Decision Records

ADRs record significant, hard-to-reverse, or cross-cutting technical decisions,
including their context and consequences.

## Workflow

1. Copy `ADR-template.md` to `ADR-NNN-short-title.md`.
2. Evaluate alternatives and trade-offs while status is `Proposed`.
3. Record the decision and responsible parties.
4. After approval, set status to `Accepted` and link relevant documents/tasks.
5. Never rewrite history. Add a new ADR and mark the previous one `Superseded`.
