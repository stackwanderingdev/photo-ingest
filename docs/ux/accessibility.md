# Accessibility

Define accessibility as a verifiable product quality. Evaluate legal duties for
the product, market, and organization separately; this template makes no blanket
claim of legal compliance.

## Minimum checks

- [ ] All functions support defined alternative input methods.
- [ ] Focus, order, and keyboard interaction are visible and predictable.
- [ ] Semantics, names, roles, states, and relationships are programmatically available.
- [ ] Information does not rely only on color, position, sound, or movement.
- [ ] Contrast, scaling, reflow, and target sizes meet the active profile.
- [ ] Forms have labels, understandable errors, and correction guidance.
- [ ] Dynamic status changes are announced appropriately.
- [ ] Animation, time limits, and automatic updates are controllable.
- [ ] Relevant browser, platform, and assistive-technology combinations were tested.

Automated scanners cover only part of accessibility. Manual keyboard checks and,
depending on risk, assistive-technology or user testing are required.
