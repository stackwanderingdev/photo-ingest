# Changelog

All notable changes to this template are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and template releases follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.0.0] - 2026-09-06

### Added

- Template validation workflow and project-mode placeholder checks.
- Release, change, and upgrade governance.
- MIT license and machine-readable license metadata.
- One-artifact-per-file structure and indexes for goals, requirements, invariants, and user journeys.
- Project-mode validation compatibility for literal release-notation examples.
- Separate bootstrap README/changelog templates and derived-project metadata.
- Explicit task index convention aligned with one-artifact-per-file storage.
- Project CI bootstrap and initialization checks that prevent derived projects from retaining template-mode CI.
- Current major versions of the official checkout and Python setup actions.

## [0.9.0] - 2026-09-05

### Added

- Technology-independent requirements, UX, architecture, engineering, ADR, and task templates.
- Binding instructions for coding agents and explicit authority/conflict handling.
- Coding standards including weighted SOLID, KISS, YAGNI, composition, and least astonishment.
- Architecture, security, testing, error-handling, and Definition of Done standards.
- Scalable UX and accessibility guidance with minimal through critical effort levels.
- Active technology stack profile and project initialization checklist.
- Iterative development workflow from product idea through controlled feedback.
- Machine-readable template identity and provenance manifest.
